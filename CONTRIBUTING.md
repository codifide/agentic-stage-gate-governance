# Contributing to Agentic Stage-Gate Governance

This template is MIT licensed and accepts contributions. The goal is to keep it practical, opinionated, and directly usable — not a framework that requires configuration before it does anything.

## What this project is

A ready-to-use governance template for AI-assisted software development. The steering files drop into any Kiro project and activate a 7-gate process with adversarial review built in. The whitepaper explains the methodology.

## Types of contributions

### Welcome
- Improvements to the steering files that make the governance process clearer or more effective
- Industry-specific gate criteria (healthcare, finance, government, etc.) as separate files or documented extensions
- Bug fixes — instructions that are wrong, broken, or misleading
- Additional example gate evidence templates
- Translations of the steering files

### Requires discussion first (open an issue)
- Changes to the core 7-gate structure (G0–G6)
- Changes to the three-model review architecture (A-Team, B-Team, Zero-Context)
- Changes to the core philosophy ("AI builds. Humans decide. Evidence proves.")

The gate structure and review architecture are the product. Changes to them need a clear rationale and discussion before a PR.

## How to submit

1. Fork the repository.
2. Create a branch from the default branch.
3. Make your changes.
4. Open a pull request with a clear description of what changed and why it makes the governance process better.

## Style

- Plain, direct language. The steering files are read by AI agents and humans alike — clarity matters more than polish.
- No jargon that isn't defined. If you introduce a term, define it.
- Keep gate criteria concrete and testable. "The design is good" is not a gate criterion. "Threat model covers the top 5 attack surfaces identified in G0 risk classification" is.
