The Problem

Agentic AI can produce 50 files in an hour. It can refactor architectures, generate test suites, and build entire features before lunch. But in healthcare — where a bug isn't a broken button but a misdirected medical record — speed without governance is just faster failure.

We took Robert Cooper's Stage-Gate® framework (1986) and rebuilt it for a world where AI agents do the building and humans do the deciding.

The Adversarial B-Team Model

The builder cannot review their own work. A separate AI (different model, different prompt, hostile personas) attacks the spec at every gate.

┌─────────────────────────────┐ │ A-TEAM (Builder) │ Claude builds the spec and code │ Writes · Builds · Tests │ └──────────────┬──────────────┘ │ submits for review ▼ ┌─────────────────────────────┐ │ B-TEAM (Critic) │ ChatGPT o3 plays 12 hostile personas: │ Different AI · Hostile │ Security red-teamer, FDA reviewer, │ Finds what builders miss │ accessibility advocate, performance │ CRITICAL / MAJOR / MINOR │ skeptic, privacy hawk, ops realist... └──────────────┬──────────────┘ │ findings returned ▼ ┌─────────────────────────────┐ │ A-TEAM Response │ Accept & fix (most common) │ Fix · Defer · Reject │ Accept & defer (with ticket) │ (reject requires evidence) │ Reject (requires counter-evidence) └──────────────┬──────────────┘ │ resubmit until PASS ▼ ┌─────────────────────────────┐ │ GATE DECISION │ │ (Human only) │ GO / KILL / HOLD │ Never automated │ └─────────────────────────────┘
Real result: First external review returned FAIL with 6 critical findings — including physically impossible storage claims and unimplementable security architecture. Four iterations later: PASS with 5 minors. Every finding accepted. Zero rejected.

Principles

1. Patient safety outranks throughput.
2. Evidence, not confidence. "We think it's fine" is not a gate pass.
3. The B-Team reviews every gate. Different AI, different blind spots.
4. AI builds. Humans decide. The gate decision is never automated.
5. 100% test coverage on new code. If AI writes it, AI tests it.
6. Security is every-gate, not a phase.
7. Accessibility is every-ticket, not a sprint.
8. Kill early, kill cheap. A failed G1 costs hours. A failed G5 costs months.

Why This Matters for Healthcare

What AI gives you

  • Code produced in hours, not months
  • 100% test coverage is achievable (AI never gets tired)
  • Comprehensive documentation generated alongside code
  • Adversarial review at scale (12 hostile personas simultaneously)

What gates give you

  • Evidence that it actually works (not just compiles)
  • Security verified before patients are exposed
  • Accessibility proven, not assumed
  • Kill decisions before bad code reaches production
  • Audit trail for compliance (HIPAA, HITRUST)

The gates aren't bureaucracy. They're the reason we caught a race condition in the submit guard, a missing file upload parameter, and an unverified certificate pinning implementation — all before any patient was affected.
